## Main Features
- A loading animation that plays when you open the website until its fully loaded with a minimum waiting time of 1 second.
- All pages have a special look similar to an old scroll made with nothing but simple css. Notice the grain and crt effect as an example.
- Ancient text characters flow from the left of the screen to the right, each designed manually according to ancient manuscripts and historical pieces spanning ancient chinese, egyptian, persian, levantine and more.
- An interactive SVG+JS based map that lets you select a continent and go into its page.
- An era selection page for each continent where you choose between Classical, Medieval & Precolonial.
- Each era of a continent has its own specially-designed portal image made with historical images from that time and geographical location.
- A subtopic selection box for each era
- Each individual subtopic page containing a two-part topic overview, up to 4 sources links to read more, and a reference picture.
- An articles page to post student articles on history, after peer reviewing and fact checking first. The page also has a submission link via google forms embedded into it.
- 
- Next to all of these the website has special css effects such as hovering animations and highlights.
