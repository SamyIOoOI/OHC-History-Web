## <p align="center">Main Features</p>
- A loading animation that plays when you open the website until its fully loaded with a minimum waiting time of 1 second.
- All pages have a special look similar to an old scroll made with nothing but simple css. Notice the grain and crt effect as an example.
- Ancient text characters flow from the left of the screen to the right, each designed manually according to ancient manuscripts and historical pieces spanning ancient chinese, egyptian, persian, levantine and more.
- A top-screen navigation panel that takes you to the different parts of the website with a special rule for the map button so that it actually sends you to the home screen when attempting to access a *non existant* map from another page to be able to access the map.
- An interactive SVG+JS based map that lets you select a continent and go into its page.
- An era selection page for each continent where you choose between Classical, Medieval & Precolonial.
- Each era of a continent has its own specially-designed portal image made with historical images from that time and geographical location.
- A subtopic selection box for each era filled with every subtopic currently included for that continent and period that sends you to its respective page.
- Each individual subtopic page containing a two-part topic overview, up to 4 sources links to read more, and a reference picture.
- An articles page to post student articles on history, after peer reviewing and fact checking first. The page also has a submission link via google forms embedded into it.
- A touch-screen & mobile device friendly layout implemented via css rules.
- Next to all of these the website has special css effects such as hovering animations, highlights and custom cursor.

## <p align="center">How To Use History Web</p>
**<p align="center">History web is designed to be straight-forward and fun to use! so almost everything is visual.</p>**

1- Select a continent from the map. Hovering on a continent will highlight it so don't worry about selecting the wrong one.

2- Select one of the 3 options now on the screen. Classical, medieval and pre/colonial. Note that classical refers to ancient history.

3- Select a subtopic from the scrollable content box you encounter and start reading. Check out the sources for detailed information. Note that not all subtopics have all sources populated and will take you to the same subtopic page if it is empty. At least 2 sources are always present.

4- When you want to go back just use the navpanel. Select something from the same era, or use the navpanel to go through it all again.

5- Alternatively if you want to view and select all of the content without using the map and the usual navigation you may use the contents page found in the navpanel. It has all of the currently included subtopics sorted by continent, era and geographical location.

## <p align="center">Website Quirks</p>

- Click the logo topleft of the screen. It will play a nice ambient storm background sound. Gets you immersed into the experience!
